# orga

An agent-native kanban board CLI written in Rust.

## Install

### mise (recommended)

```bash
mise use github:twistedogic/orga
```

### Direct download

Download the latest binary for your platform from the [releases page](https://github.com/twistedogic/orga/releases) and place it in your `$PATH`.

| Platform | Asset |
|---|---|
| macOS (Apple Silicon) | `orga-aarch64-apple-darwin.tar.gz` |
| macOS (Intel) | `orga-x86_64-apple-darwin.tar.gz` |
| Linux (x86_64) | `orga-x86_64-unknown-linux-gnu.tar.gz` |
| Linux (ARM64) | `orga-aarch64-unknown-linux-gnu.tar.gz` |
| Linux (ARMv7 / Raspberry Pi) | `orga-armv7-unknown-linux-gnueabihf.tar.gz` |
| Windows (x86_64) | `orga-x86_64-pc-windows-msvc.zip` |
